==== আপনার ওয়েবসাইট ====

ফোল্ডারে যা আছে:
  index.html   -> মূল ওয়েবসাইট (সব কোড এখানে)
  photos/      -> আপনার ছবি এই ফোল্ডারে রাখুন
  README.txt   -> এই নির্দেশনা

১) ছবি যোগ করা (সবচেয়ে সহজ)
   - photos ফোল্ডারে ছবি রাখুন, নাম দিন 1.jpg, 2.jpg, 3.jpg ... এভাবে।
   - তারপর index.html খুললেই ছবিগুলো গ্যালারিতে দেখা যাবে।
   - ছবি বদলাতে চাইলে একই নামে নতুন ছবি দিয়ে পুরনোটা বদলে দিন।

২) লেখা ও লিংক বদলানো
   - index.html কে Notepad / VS Code দিয়ে খুলুন।
   - ফাইলের ভেতরে "const CONFIG = {" খুঁজুন। সব লেখা ওখানেই আছে:
       title, lead      -> বড় শিরোনাম ও পরিচিতি
       secrets          -> তালা দেওয়া ৩টি কার্ড (hint = প্রশ্ন, url = আপনার লিংক)
       button1, button2 -> নিচের দুটি বাটনের লেখা
   - শুধু "" ভেতরের লেখা বদলান, বাকি অংশ ছুঁবেন না।

৩) কম্পিউটারে দেখা
   - index.html ডাবল ক্লিক করুন, ব্রাউজারে খুলবে।

৪) অনলাইনে দেওয়া (ফ্রি)
   - GitHub Pages: নতুন repository খুলে সব ফাইল আপলোড করুন, Settings > Pages থেকে চালু করুন।
   - অথবা Netlify Drop (app.netlify.com/drop): পুরো ফোল্ডারটি টেনে এনে ছেড়ে দিন।

মনে রাখবেন: পেজ থেকে "＋ ছবি যোগ করুন" দিয়ে যে ছবি দেবেন তা শুধু আপনার ব্রাউজারে থাকে।
সবাই দেখবে এমন ছবির জন্য photos ফোল্ডারে রাখতে হবে।

৫) লিংক কীভাবে কাজ করে
   - যেকোনো লিংকে ক্লিক করলে ওয়েবসাইট যেমন আছে তেমনই থাকে, লিংক নতুন ট্যাবে খোলে।
   - নতুন ট্যাব আটকে গেলে (কিছু অ্যাপের ব্রাউজারে হয়) লিংক এই পেজের ওপরেই একটি ভিউয়ারে খোলে।
   - url-এ https:// না লিখলেও চলবে: facebook.com/পেজ, wa.me/নম্বর, ইমেইল বা ফোন নম্বর সবই কাজ করবে।
   - links-এর কোনো url বসালে "শুধু আপনার জন্য" অংশটি নিজে থেকে দেখা যাবে।
